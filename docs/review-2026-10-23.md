# Review, 2026-10-23

## Changes

- Serialize repository mutations with a mutex and write indexes with AtomicFile before publishing state. Corrupt indexes are preserved and an error is shown instead of replacing the library with an empty index.
- Updates transform the latest document, preventing concurrent tags/page edits from losing each other. New-document navigation waits for persistence.
- Delete unreferenced originals, edited images and imported documents after saving the index, including images stored under inbox/temporary import directories. Shared files are retained.
- Store portable paths; resolve legacy absolute paths after restore. Include scans in backup/device transfer and exclude old generated exports. New exports use cache storage.
- Remove the camera-permission gate and its unused screen/strings/helper. ML Kit owns the camera flow and does not require app camera permission: https://developers.google.com/ml-kit/vision/doc-scanner.
- Crop handles align with the fitted original image; callbacks use current state and ordered bounds. Processed preview and viewer thumbnails reflect filters and rotation. Manual movement invalidates pending automatic detection. Filter controls scroll on narrow screens.
- Respect EXIF orientation, bound bitmap previews/PDF imports, correct black-and-white luminance and handle crop coordinates on the final pixel safely.
- Imports reject unavailable streams; exports report errors, release the busy state, reject missing pages and isolate each share in a unique directory. Close OCR resources.
- Removed unused date formatter, repository directory wrapper, unreachable reorder helper, imports and scanner PDF output that was never consumed. README now matches the available page-management controls.

## Validation

- All application Kotlin sources and 10 new Android instrumentation tests compiled through a fallback local K2 compiler (2.0.21), Compose compiler and cached Android libraries. Some cached Compose dependencies differ from the declared Gradle versions; this verifies source consistency, not the production build graph.
- `git diff --check`: passed.
- Gradle build/test/lint attempted. The declared Gradle 8.9 distribution is not cached. The managed environment prevents Java from resolving services.gradle.org. The normal build and lint did not run.
- Instrumentation tests cover concurrent document insertion, concurrent tag transforms, inbox/shared file cleanup, imported-file cleanup, corrupt-index preservation, folder deletion, portable paths, EXIF rotation, edge and inverted crops. They have been compiled but NOT executed on Android.
